## 二、本地预览方式

本项目采用零外部构建依赖的纯静态模块化架构：
- **方式 1（直接双击运行）**：直接在浏览器（Edge / Chrome / Firefox / Safari）中打开 [`index.html`](./index.html) 即可离线运行全部 3D 实验。
- **方式 2（本地静态服务器）**：使用 VS Code `Live Server` 插件或任意静态 HTTP 服务打开项目根目录。

## 三、发布到 GitHub Pages 指南

仓库已内置 [`.nojekyll`](./.nojekyll)、[`.gitignore`](./.gitignore)（已自动忽略超过 100MB 的参考 PDF 文件，避免推送报错）以及自动部署工作流 [`.github/workflows/deploy.yml`](./.github/workflows/deploy.yml)。

### 方法 A：网页端直接上传或 Git 推送 + 分支部署（最简）
1. 在 GitHub 新建公开仓库（例如 `intelligent-info-processing-3d-lab`）。
2. 将除 `.pdf` 以外的网页源码文件（`index.html`、`css/`、`js/`、`.nojekyll`、`README.md`、`.github/`）上传或 `git push` 到 `main` 分支：
   ```bash
   git init
   git add .
   git commit -m "Initial commit: Intelligent Information Processing 3D Lab"
   git branch -M main
   git remote add origin https://github.com/<你的用户名>/<仓库名>.git
   git push -u origin main
   ```
3. 打开 GitHub 仓库页面 → **Settings** → **Pages**：
   - **Build and deployment** → **Source** 选择 `GitHub Actions`（使用内置自动工作流）**或** 选择 `Deploy from a branch`（Branch 选 `main` / `/ (root)`，点击 Save）。
4. 等待约 30–60 秒后，即可通过 `https://<你的用户名>.github.io/<仓库名>/` 在线访问！
